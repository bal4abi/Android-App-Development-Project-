# Priorify Hub

A task manager app for Android that helps users keep track of tasks, due dates, and priorities.

## Completed So Far
- Project outline and plan (see Wiki)
- App Design and Development Wiki, including hand-drawn wireframes and wireframes built in Justinmind
- Database Design Wiki page (planned task fields and storage approach)
- Android Studio project created (Empty Views Activity, Java)
- Main screen built: task input box, Add Task button, and task list
- Tasks save with SharedPreferences (JSON) and reload when the app reopens

## In Progress
- Priority selection (High, Medium, Low) and grouped task lists
- Due dates
- Mark tasks complete or delete them
- Calendar view and reminders

## Tech
- Android Studio (Java)
- SharedPreferences with JSON
- Justinmind (wireframes)
- GitHub

## Wireframes
Hand-drawn wireframes are in the `design` folder. Screen 1 shows the task list grouped by priority. Screen 2 shows the calendar view.

## How to Run
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Click Run to start the app on an emulator or Android device.
